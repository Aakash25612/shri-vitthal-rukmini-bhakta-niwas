# Shri Vitthal Rukmini Bhakta Niwas

Static website for the devotee stay at Bhakti Marg, Sangola Naka, Pandharpur.

Room rates, the phone number and photos are set in the `CONFIG` block in `index.html`.

## Deploy

Import this repository in Vercel. Framework preset: Other. The site is a single `index.html` page, so no build command is needed.

After the live URL exists, add it as the website on the Google listing for Shri Vitthal Rukmini Bhakta Niwas, then add that same URL to `sitemap.xml` and `robots.txt`.
